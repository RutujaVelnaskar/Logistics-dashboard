# Logistics Dashboard

## Project Overview
This project is a Power BI dashboard created to analyze logistics and shipment data.

## Dashboard Features
- Total Shipments
- Total Freight
- Total Containers
- Total Consignees
- Shipment Status Analysis
- FCL vs LCL Shipment Analysis
- Freight by Port
- Port-wise Freight Details

## Tools Used
- Power BI
- Power Query
- DAX
- Data Modeling

## Project Objective
The dashboard provides an easy-to-understand view of logistics operations and helps analyze shipment status, freight and port-wise performance.
